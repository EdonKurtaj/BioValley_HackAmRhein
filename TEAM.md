## Working rules

- Branches `<type>/<task>-<topic>` (e.g. `feat/t3-csv-upload`), never a person's name, never commit to `main` directly.
- `bash scripts/hack-guard.sh` must pass before every commit and push. Never `--no-verify`.
- Every change goes in through a pull request. The author checks and may merge their own pull request; Codex-assisted merges still require the author's explicit yes for that pull request.
- Merge policy: author merges after checking their changes.
- Sync times: as needed by the team.
- Keep `main` working at all times, so the demo can run whenever it's needed.
- Decisions that affect others: `docs/decisions.md`.
- Secrets in `.env` only. Data sources in `docs/SOURCES.md`.
