## Colour roles
| Token | Used for |
|---|---|
| `primary` | main actions |
| `background` | page background |
| `surface` | cards, panels |
| `text` | body text |
| `ok` / `warning` / `error` | status, always with an icon or word |

## Type
| Token | Used for |
